## 文書の性格

本仕様書は「AI画像生成の仕様書」ではなく、**人物アイデンティティ（その人らしさ）を維持したまま、実写・アニメ・レトロ映画風など多様な表現へ変換できるシステムの設計標準書**です。

中核となる思想は、人物を構成する要素を五層（アイデンティティ・属性・スタイル・シーン・時間）に分離して管理することです（第5章）。
