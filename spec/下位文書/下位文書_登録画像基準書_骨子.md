# 登録画像基準書

Version 0.1（骨子）

## 0. 位置付け

- **上位文書**：人物アイデンティティ維持型AI画像生成システム 技術仕様書
- **委任条項**：1.8.3、6.4（顔品質判定）、6.7.2（登録画像の構成要件）
- **本文書の性格**：上位文書が「測定項目」までを定め、具体的なしきい値・必須枚数を本文書に委ねている（P-09）。顔認証モデルの交代に応じて改訂する。

## 1. 目的

本文書は、人物登録時に用いる画像の品質基準および構成要件について、具体的な数値・枚数を定める。

## 2. 適用範囲

人物登録（16.2.1）における登録画像の受入判定に適用する。
