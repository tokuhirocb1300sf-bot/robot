# インシデント対応手順書

Version 0.1（骨子）

## 0. 位置付け

- **上位文書**：人物アイデンティティ維持型AI画像生成システム 技術仕様書
- **委任条項**：1.8.3、15.8（インシデント対応）
- **本文書の性格**：発生時に迅速に参照される実務手順書であるため、上位文書より簡潔・具体的な記述とする。

## 1. 目的

本文書は、15.8 に定めるインシデント類型ごとの、具体的な対応手順・連絡体制・報告様式を定める。

## 2. 適用範囲

本システムの運用中に発生する、人物情報・生成物・システムに関わるインシデントに適用する。
