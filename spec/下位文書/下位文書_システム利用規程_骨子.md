# システム利用規程

Version 0.1（骨子）

## 0. 位置付け

- **上位文書**：人物アイデンティティ維持型AI画像生成システム 技術仕様書
- **委任条項**：1.8.3、15.7.1（禁止用途）
- **本文書の性格**：全利用者が実際に読み、同意する規程である。上位文書より平易な記述とし、教育（16.7.1）の教材として用いる。

## 1. 目的

本規程は、本システムの利用者が遵守すべき事項を定める。

## 2. 適用範囲

本システムにアクセスする、すべての利用者（第2章 2.1.3 に定める全役割）に適用する。

### 3.2　利用者の遵守事項

| 項目 | 内容 |
|---|---|
| 同意確認 | 人物登録前に、権利者の同意取得を確認すること（16.2.1） |
| 権限の範囲内での利用 | 付与された権限（7.7）を超えて操作しないこと |
| 生成物の取扱い | 承認（16.3.1）を経ない生成物を公開・配布しないこと |
| 異常の報告 | 禁止用途に該当しうる事象を発見した場合、速やかに報告すること |
| アカウントの管理 | 認証情報を第三者と共有しないこと |
