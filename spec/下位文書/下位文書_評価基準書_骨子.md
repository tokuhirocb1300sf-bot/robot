# 評価基準書

Version 0.1（骨子）

## 0. 位置付け

- **上位文書**：人物アイデンティティ維持型AI画像生成システム 技術仕様書
- **委任条項**：1.8.3、11.8（受入基準の設定）、11.7.3（PIQI重み）、12.9.2（動画受入基準）
- **本文書の性格**：本仕様書全体の中で、実質的に**改訂頻度が最も高い**下位文書である。顔認証モデル・生成モデルの交代、スタイルプロファイルの追加のたびに更新される。

## 1. 目的

本文書は、人物同一性評価（第11章）および動画評価（第12章）において用いる、具体的な受入基準値を定める。

## 2. 適用範囲

E1（特徴量比較）・E2（幾何特徴照合）・E3（目視評価）の総合判定、および動画の受入基準判定に適用する。
